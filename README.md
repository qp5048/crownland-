# CrownLand.io

Браузерная игра в жанре paper.io (захват территории) для CrazyGames. HTML5 Canvas, ES-модули и Vite. На выходе статическая сборка примерно на 290 КБ: без внешних ассетов, звук и музыка синтезируются процедурно, шрифт Rubik встроен в сборку.

```bash
npm install
npm run dev       # локальный сервер разработки
npm test          # автотесты (node --test): заливка, мир, экономика, сохранения, прогрессия, реклама
npm run build     # статическая сборка в dist/
npm run preview   # проверка собранной версии
```

Для загрузки на CrazyGames заархивируйте содержимое `dist/`. Пути относительные (`base: './'`), поэтому сборка запускается из любой папки и без сервера.

Старый однофайловый прототип перенесён в `legacy/prototype.html` и в сборку не входит.

## Архитектура

```
src/
  config.js            все константы баланса (скорость, экономика, реклама, карты)
  main.js / app.js     загрузка, экраны, жизненный цикл матча, SDK, сохранения
  core/                фиксированный цикл (60 тиков/с + интерполяция), ввод, RNG, математика, события
  game/
    grid.js            сетка владения + заливка (BFS) — чистая логика
    world.js           детерминированная симуляция: движение, след, столкновения, захват, смерть
    match.js           режимы (обычный/рейтинг/туториал/демо), боты, бусты, продолжение, победа
    renderer.js        камера, территория с объёмом, волны захвата, следы, головы, частицы, мини-карта
    particles.js       пул частиц на typed arrays
  ai/                  ИИ ботов (машина состояний, BFS-пути, просчёт риска), профили сложности, ники
  cosmetics/           каталог (46 скинов, 19 украшений, 17 следов, 4 буста) и векторная отрисовка
  shop/economy.js      монеты, покупки, бусты — чистые функции
  ranked/ranks.js      17 рангов, очки ранга, сложность от ранга, SVG-иконки
  battlepass/          сезон, 30 уровней, две дорожки, задания дня, ежедневная награда
  audio/audio.js       Web Audio: SFX и две музыкальные петли, глушение по причинам
  ads/                 обёртка CrazyGames SDK v3 + полноценный мок, политика показа рекламы
  save/                схема с версией и миграциями, санитизация, бэкап, хранилища
  i18n/                strings.js (все строки EN/RU) + i18n.js (подстановки, плюральные формы)
  ui/                  DOM-интерфейс: меню, HUD, магазин, пропуск, диалоги, туториал, превью
tests/                 автотесты критичной логики
```

Модули `game/grid`, `game/world`, `ai`, `shop`, `ranked`, `battlepass`, `save` и `ads/ads` не трогают DOM, поэтому тестируются в Node без браузера.

### Ключевые решения

- **Цикл.** Логика работает фиксированным шагом 60 тиков/с, рендер интерполирует позицию между тиками. Дельта кадра ограничена 0.25 с, за кадр выполняется не больше 6 шагов, поэтому после сворачивания вкладки симуляция не «догоняет» рывком.
- **Движение и след.** Движение непрерывное, с ограниченной скоростью поворота, как в paper.io 2. Каждый тик голова проходит не больше 0.17 клетки (с ускорением), поэтому клетки не пропускаются. Если голова пересекает угол сразу двух клеток, сначала засчитывается промежуточная клетка. След всегда связан по 4 соседям, и проскочить его по диагонали нельзя (покрыто тестами на 17 углах и скорости ×2.2).
- **Заливка.** Клетки следа становятся своими, затем BFS от границы карты по чужим клеткам помечает «снаружи». Заливаются только области, которые касаются нового следа. Старые дыры остаются дырами, чужая земля внутри петли переходит игроку. Область у края карты замыкается, только если краевые клетки уже твои. Счётчики территории обновляются инкрементально, тесты сверяют их с полным пересчётом.
- **Столкновения.** Решаются в три фазы за тик: движение всех игроков, затем проверка смертей по состоянию до новых отметок (одновременные пересечения честные), затем отметки следа и захваты с ротацией приоритета. Если игрок потерял всю землю, он выбывает, а убийство засчитывается захватчику.
- **Ранговая передача.** Сначала все жертвы тика помечаются мёртвыми, только потом земля передаётся убийце. При взаимных убийствах земля не уходит «трупу».
- **ИИ.** Боты работают как машина состояний: «дом», «расширение» (прямоугольные петли с оценкой выгоды), «возврат» (BFS домой в обход своего следа), «охота» и «оборона». Риск оценивается так: путь домой плюс запас сравнивается с тем, сколько ближайшему врагу нужно до моего следа или головы. Каждый тик бот просчитывает упреждающую траекторию с учётом радиуса поворота и проверяет стены, свой след и чужие головы. Характеры: осторожный, агрессивный, жадный, сбалансированный. Параметры сложности (реакция, агрессия, размер петель, точность, «человеческие» ошибки) плавно интерполируются от ранга.

## CrazyGames SDK v3

- SDK подключается тегом из документации. Если он не загрузился или `environment === 'disabled'`, автоматически включается мок с тем же API и имитацией рекламы (`src/ads/sdk.js`).
- `gameplayStart()` вызывается при старте матча, после паузы и после продолжения. `gameplayStop()` вызывается на паузе, при смерти (пока открыто окно «Продолжить?»), в конце матча и в меню. Вызовы сбалансированы через `GameplayTracker`.
- `happytime()` вызывается при новом рекорде, победе, повышении ранга и открытии премиум-пропуска.
- `loadingStart/Stop` вызываются во время загрузки.
- **Midgame** показывается только между матчами: после экрана результатов, перед следующим стартом или возвратом в меню. Не раньше, чем после 2-го матча, и не чаще раза в 3 минуты. Во время игры и до первого матча реклама не показывается.
- **Rewarded** показывается только по нажатию игрока: «Удвоить монеты», «Продолжить» (один раз за матч, недоступно в рейтинге), 7 просмотров для премиум-пропуска, «×2» к ежедневной награде, бесплатный буст (3 в день). Награда выдаётся только по `adFinished`. Для `adError` и adblock показывается сообщение, игра продолжается. Есть страховочный таймаут 90 с.
- Во время рекламы звук глушится, симуляция и ввод останавливаются. Настройка `muteAudio` из SDK тоже учитывается.
- Прогресс хранится в `SDK.data`, если он доступен, иначе в `localStorage`, иначе в памяти. Своей кнопки полного экрана на CrazyGames нет (у площадки своя), внешних ссылок и сторонней рекламы тоже нет.

## Найденные и исправленные баги

1. **Боты погибали на углах собственного следа.** Упреждающая проверка смотрела только клетку под точкой траектории, а настоящая голова задевает и угловые клетки. Теперь проверяется квадрат ±0.32 клетки. На максимальной сложности самоубийств было 17 за 10 минут, стало 0.
2. **Ранговая передача могла «убить» игрока его же следом.** Если в результате передачи клетки следа становились своими, это считалось самопересечением. Теперь петля просто замыкается.
3. **Взаимное убийство в рейтинге могло отдать землю погибшему.** Теперь все жертвы помечаются мёртвыми до передачи земли (покрыто тестом).
4. **Бот вне дома в состоянии «дом» ехал прямо до стены.** Теперь такое состояние переводится в «возврат».
5. **BFS создавал массив на каждой клетке** (лишняя нагрузка на сборщик мусора). Переписан без аллокаций.
6. **Сохранение обнуляло очки ранга «Легенда».** Выражение `need - 1 || 0` при `need = 0` давало −1. Исправлено и покрыто тестом.
7. **Производительность.** Штриховка за пределами карты рисовалась линиями на весь экран каждый кадр, даже когда край карты не виден. Теперь это кэшированный паттерн, который рисуется только при видимом крае. Под 4-кратным замедлением CPU кадр сократился с 70 до 32 мс. Добавлено автопереключение на быструю графику при долгой просадке FPS.
8. **В плитках меню появлялся текст «null»** (`replaceChildren` с пустыми значениями).
9. **«Пройти обучение заново» из меню паузы сразу ставило туториал на паузу.** Добавлена проверка, что матч не сменился.
10. **Конфетти от уже закрытого окна результатов вылетало в левый верхний угол.** Добавлена проверка `isConnected`.
11. **В туториале игрок мигал всё время и показывался «щит»** из-за технической неуязвимости. Мигание и щит теперь показываются только при настоящей короткой неуязвимости.
12. **Демонстрация в туториале зависала, если манекен B погибал раньше A.** Теперь засчитывается любая гибель.
13. **Цель туториала могла оказаться за экраном.** Добавлена стрелка у края экрана.
14. **Карта туториала была слишком тесной** (игрок упирался в стену через ~3 с). Увеличена с 44 до 64 клеток.
15. **Цифры отсчёта не читались на светлом поле.** Теперь они золотые с белой обводкой.
16. **Строка «Ranked ×0.5 ×0.5» дублировала множитель.**
17. **Миниатюры эксклюзивов в магазине сжимались** из-за flex-сжатия.
18. **Неверные русские плюральные формы** («Выбей 3 соперников»). Используются формы через `Intl.PluralRules`.
19. **«Плита» земли в превью занимала полкарточки.** Превью переделано.
20. Две ошибки в самих тестах (сцена одновременного захвата и геометрия теста на перерезание следа) исправлены, проверки стали строже.

### Что проверить вручную перед публикацией

- Песочница разработки не имела доступа к `sdk.crazygames.com`, поэтому реклама и Data-модуль проверены на моке. Перед релизом прогоните сборку через QA-инструмент CrazyGames (в режиме `local` SDK показывает демо-рекламу).
- Производительность измерялась в headless Chromium с программной растеризацией. На реальном устройстве с GPU стоит проверить FPS на слабом телефоне.
