# Chop Hop! 🔪🍉

3D-гиперказуалка для браузера (ПК и телефоны): прыгай клинком, переворачивайся, втыкайся остриём в землю и режь всё на пути. Вдохновлено жанром «slice-игр», но механики, финал, мета-прогрессия и контент свои.

## Чем отличается от Slice Master

| Slice Master | Chop Hop |
|---|---|
| В конце башня с множителями | **Финальный бросок в мишень-дартс**: прицел ездит по мишени, нужно попасть в нужный момент (x2 … x25 в яблочко). На поздних уровнях прицел двигается неравномерно |
| Нет боссов | **Босс каждые 5 уровней**: Арбузный король, Ананас, Король-пончик, Снеговик, Неон-куб. У каждого полоска здоровья, ворота открываются только после победы. С 10-го уровня босс плюётся косточками, их можно разрубить |
| — | **Режим «Ярость» (FEVER)**: быстро режешь → шкала заполняется → монеты x2, клинок горит, шипы и пилы разбиваются |
| — | **Идеальное приземление** (остриё ровно вертикально) даёт бонус «PERFECT» |
| Шипы | Шипы, **выдвижные шипы**, **циркулярные пилы** на рельсах |
| — | **Батуты-желе**, **золотые кольца-ускорители**, **пузырь-щит**, **золотые фрукты** |
| — | **3 звезды на уровне**: спрятаны в рискованных местах, открывают клинки |
| Один мир | **5 миров**: Сочный луг, Закатный каньон, Конфетные облака, Морозные пики, Неоновая ночь (свои предметы и декор) |
| Магазин ножей | **12 клинков** (тесак, кунай, катана, багет, лазерный меч, магма, радуга…), которые открываются за монеты, звёзды, уровень или рекламу. Плюс **полоса «новый клинок»** после уровней |
| — | **Улучшения**: доход, длительность ярости, магнит для монет, шанс начать со щитом |
| — | **Колесо удачи**: бесплатно раз в 3 часа, дополнительно за рекламу |
| — | Комбо-серии, брызги и пятна сока, честная физика разрезанных половинок с мякотью внутри |
| — | Языки: English и Русский (определяется автоматически, можно сменить в настройках) |

Звуки и музыка генерируются кодом, поэтому в игре нет ни одного внешнего файла ассетов.

## Как запустить

Готовая игра лежит в `dist/`: это два файла, `index.html` и `game.js`. Открой `dist/index.html` в браузере (работает даже двойным кликом) или залей папку на любой хостинг.

Управление: клик, тап, **Пробел** или **↑** прыгает и переворачивает клинок, **Esc** или **P** ставит паузу.

## Как отправить на CrazyGames

1. Запакуй **содержимое** папки `dist/` в zip (`index.html` и `game.js` должны лежать в корне архива).
2. В CrazyGames Developer Portal выбери тип «HTML5» и загрузи zip.
3. Обложки уже готовы в `covers/`: 1920×1080, 800×1200, 800×800.
4. CrazyGames SDK v3 уже подключён (`src/sdk.js`):
   - `loadingStart/Stop`, `gameplayStart/Stop`, `happytime`;
   - midgame-реклама между уровнями (не чаще раза в 2,5 минуты, начиная с 3-го уровня);
   - rewarded-реклама: воскрешение, «Забрать x3», бесплатные монеты, лазерный меч, повторное вращение колеса;
   - на время рекламы звук ставится на паузу;
   - сохранение идёт через `SDK.data` (облако CrazyGames), без SDK используется `localStorage`.

   Вне CrazyGames реклама имитируется (короткая заглушка), так что все функции можно проверить локально.

## Разработка

```bash
cd chop-hop
npm install
npm run build    # собирает src/ → dist/
npm run watch    # пересобирает при изменениях
```

Структура `src/`:

| Файл | Что внутри |
|---|---|
| `main.js` | игровой цикл, состояния, нарезка, ярость, босс, финальный бросок, награды |
| `player.js` | физика клинка (переворот, втыкание, отскоки) и шлейф |
| `level.js` | процедурный генератор уровней и их 3D-модели |
| `items.js` | фрукты, пончики, доски и т.д. (что можно резать) |
| `skins.js` | 12 клинков и превью для магазина |
| `world.js` | 5 миров: небо, холмы, деревья, облака |
| `fx.js` | разрезание на половинки (clipping planes), частицы, пятна, всплывающие числа |
| `ui.js`, `index.html` | интерфейс: меню, магазин, колесо, окна |
| `meta.js` | цены, улучшения, призы колеса |
| `audio.js` | синтезированные звуки и музыка |
| `sdk.js` | обёртка CrazyGames SDK |
| `i18n.js` | тексты EN/RU |

Переименовать игру можно в двух местах: `<title>` и блок `#logo` в `src/index.html`.
